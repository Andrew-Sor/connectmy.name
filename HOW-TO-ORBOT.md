# Как установить и использовать Orbot

Это краткое руководство по настройке Orbot для работы с этим приложением. Оно включает в себя настройку моста для обхода запрета использования Tor.

## Установка

Установите Orbot из [Google Play](https://play.google.com/store/apps/details?id=org.torproject.android), с [официального сайта](https://guardianproject.info/releases/orbot-latest.apk) или с [GitHub](https://github.com/guardianproject/orbot-android/releases).

## Настройка моста

> [!NOTE]
> Этот раздел предназначен только для тех, в чьей стране использование Tor запрещено (например, Россия). Если у вас Tor не запрещён, то вы готовы к использованию.

Для настройки моста нажмите на `Настроить транспорт`.

<img width="571" height="1280" alt="-211237_temp" src="https://github.com/user-attachments/assets/18aadc87-d30e-4aad-8417-f9cd5e2c9275" />

Для начала вам понадобится сам мост. Есть 2 варианта:

1. Встроенные мосты, включая "Умное подключение", которое автоматически выбирает лучший путь. (У меня ни один встроенный вариант не работал)
2. Сторонние мосты, которые можно найти в интернете или [получить на официальном сайте Tor](https://bridges.torproject.org/options/ru) (он заблокирован в России и для него нужен любой другой VPN).

У меня сработал только мост с официального сайта Tor. Можете тоже его попробовать:
```
obfs4 31.171.241.238:8414 811115E721E9B530A3BA41D3FCE6B71D64E4DC5A cert=Sye+7gmUheN9ohPm8TV1pyNiuMwr4NMAKJXC3p6Du8m56VyorhG6S7u2NgklFS91rwpKBA iat-mode=0
```

Чтобы использовать сторонний мост, нужно выбрать `Пользовательские мосты`, `Далее`, вставить мост и `Подключить`.

<img width="4096" height="4425" alt="IMG_20260830_183027" src="https://github.com/user-attachments/assets/380bc5ec-9ec2-4274-8636-4ec34e10ab17" />

После этого вы будете подключены к Tor.

<p align="center"><b>Поздравляем! Вы готовы к использованию!</b></p>
