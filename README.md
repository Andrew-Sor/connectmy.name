# connectmy.name

Это приложение позволяет получать неограниченное количество пробных периодов для hidemy.name VPN и автоматизировать этот процесс. Для работы требуется Orbot.

## Установка

Просто скачайте `.apk`-файл последнего релиза на странице [релизов](https://github.com/Andrew-Sor/connectmy.name/releases).

> [!TIP]
> Рекомендуется иметь уже установленные Orbot и сам hidemy.name VPN. В случае их отсутствия будет предложено их установить.

## Использование

> [!IMPORTANT]
> При первом запуске вам необходимо задать некоторые параметры. Нажмите на `•••` в правом верхнем углу, выберите `Настройки` и следуйте [инструкции](#настройка).

1. При нажатии кнопки `Получить пробный период` откроется Orbot для подключения к Tor.
2. После подключения вернитесь в приложение. Приложение начнёт отправлять запрос на получение пробного периода на свободный адрес (тот, на который приложение ещё не запрашивало пробный период) с разных IP-адресов до тех пор пока не будет отправлен код. 
3. После удачного запроса будет опять запущен Orbot для отключения от сети Tor.
4. После отключения вернитесь в приложение. В зависимости от настроек приложение либо начнёт поиск кода на указанных почтовых ящиках либо откроет приложение или сайт выбранного почтового сервиса.
5. После удачного поиска кода и копирования его в буфер обмена либо возвращения из приложения или браузера почтового сервиса будет запущен hidemy.name VPN для активации кода и подключения.

## Настройка

### Список адресов электронных почт

Для начала вам необходимо ввести 7 адресов электронных почт, которые вы хотите использовать для получения пробного периода.

> [!TIP]
> Почему 7? Потому что каждый адрес эл. почты запоминается сайтом на 7 суток, и в течении этого времени на него невозможно получить новый пробный период.

> [!IMPORTANT]
> Вводите реальные адреса почт, к которым вы можете получить доступ. Именно на них будет приходить код, который необходимо ввести в hidemy.name VPN.

> [!NOTE]
> Лайфхак: для Яндекс Почты можно использовать 5 адресов благодаря различным доменам. Например, вместо 1-го `example@yandex.ru` можно использовать 5: `example@ya.ru`, `example@yandex.ru`, `example@yandex.by`, `example@yandex.kz` и `example@yandex.com`. Письмо с кодом будет приходить в один и тот же ящик 

### Способ извлечения кода

Вам необходимо выбрать каким способом вы получите сам код. Доступны 2 способа: автоматический (с помощью IMAP) и ручной (открытие приложения или сайта почтового ящика).

#### Настройка IMAP

Тут необходимо указать учётные данные и настройки подключения к серверу IMAP (можно выбрать из готовых настроек для некоторых почтовых сервисов).

Также можно добавлять до 7 аккаунтов для последовательной проверки каждого из них.

> [!NOTE]
> Некоторые почтовые сервисы в качестве пароля требуют специальный "Пароль приложения". Например, Яндекс Почта и Почта Mail.Ru.

> [!IMPORTANT]
> Не забудьте проверить доступность сбора почты по протоколу IMAP для вашего аккаунта!

> [!TIP]
> Настройки подключения для других почтовых сервисов уточняйте на этом сервисе или в интернете.

#### Настрока запуска почтового приложения

Тут можно выбрать то почтовое приложение, которым вы пользуетесь. Доступно несколько предложений и выбор своего.

#### Настройка открытия сайта почтового сервиса

Тут можно выбрать тот почтовый сервис, которым вы пользуетесь. Доступно так же несколько готовых и ввод своего URL-адреса почтового сервиса.

> [!NOTE]
> Если вы введёте URL без `https://` или `http://`, то приложение автоматически подставит `https://`.

## Вопросы

> Я не понимаю смысла этого приложения! Почему нельзя просто получить пробный период с помощью официального сайта?

Можно. Но это приложение немного автоматизирует процесс и решает главную проблему — при частом запросе подобного доступа ваш IP тоже запоминается (причём на более длительный срок).

> Это приложение отправляет мои данные третьим лицам?

Нет. Можете сами проверить исходный код и даже самостоятельно собрать из него приложение.
